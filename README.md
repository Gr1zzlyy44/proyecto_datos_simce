# PROYECTO SIMCE 

## Descripción

SIMCE: Evaluación estandarizada que se aplica anualmente en Chile para medir el logro de los contenidos y habilidades del Currículum Nacional en los establecimientos educacionales.

La pregunta principal del proyecto es: ¿De qué manera se puede explicar las diferencias de resultado SIMCE entre colegios con nivel socioeconómico similar y qué tienen en común los colegios que rinden por sobre lo esperado? ¿Hay colegios con bajo nivel socioeconómico que tengan muy buenos resultados en el SIMCE? Si es así, ¿son resultados consistentes en el tiempo? ¿Cuál de estos patrones podría servir de pista para otros colegios?.

## REQUISITOS
- Python  V.3.12
- PostgreSQL V.18
- DBeaver
- Power Bi
